# blobs

`u1f600.png` and friends are Google's blob emoji from Noto Emoji, the last release before the blobs were retired
([googlefonts/noto-emoji, tag v2017-05-18-cook-color-fix](https://github.com/googlefonts/noto-emoji/tree/v2017-05-18-cook-color-fix/png/128)).
Noto Emoji is under the Apache License 2.0, the same as this repo (see `LICENSE` at the root). File names are the emoji's codepoint.

Which face someone gets is picked from their account number, see `sitefunctions::BLOB_AVATARS`.
